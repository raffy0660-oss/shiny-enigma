# Skills

Skill folders here are copied from https://github.com/juliusbrussee/caveman
(commit b4ee71d), licensed Apache-2.0 (see LICENSE-caveman).

Claude Code loads every `<name>/SKILL.md` in this folder automatically.
Main skill: `/caveman` (also `/ultracave`, `/megacave`).

`find-skills/` is copied from https://github.com/vercel-labs/skills
(commit b716f9d), MIT license (see find-skills/LICENSE).

`pion-raja/` is the creator's own character engine (uploaded by the repo owner).

`remotion-best-practices/` is copied from https://github.com/remotion-dev/skills
(commit 7e541aa). It routes to every Remotion sub-skill (create, markup, captions,
render, studio, multimedia, maps, interactivity, docs, upgrade, license, saas).
