# Skills

Skill folders here are copied from https://github.com/juliusbrussee/caveman
(commit b4ee71d), licensed Apache-2.0 (see LICENSE-caveman).

Claude Code loads every `<name>/SKILL.md` in this folder automatically.
Main skill: `/caveman` (also `/ultracave`, `/megacave`).

`find-skills/` is copied from https://github.com/vercel-labs/skills
(commit b716f9d), MIT license (see find-skills/LICENSE).

`pion-raja/` is the creator's own character engine (uploaded by the repo owner).

`remotion-best-practices/` is copied from https://github.com/remotion-dev/skills
(commit 7e541aa). It routes to every Remotion sub-skill (create, markup, captions,
render, studio, multimedia, maps, interactivity, docs, upgrade, license, saas).

`yt-*` (11 skills) are copied from https://github.com/Jakeschincariol/youtube-agent-skill
(commit a2feb21), MIT. Voice profile path changed to `.claude/youtube/voice.md` in this repo
(fill in that template), falling back to `~/.claude/youtube/voice.md`.

`threejs-*` (13 skills) are copied from https://github.com/CloudAI-X/threejs-skills
(commit 0e18186), MIT.

`elevenlabs-*` (12 skills) are copied from https://github.com/elevenlabs/skills
(commit 1d84076), MIT. Folder and skill names got an `elevenlabs-` prefix. Needs an
ElevenLabs API key (paid service).

Herk Edit Kit skills (cut-mistakes, cut-silences, edit-video, gsap, hyperframes*,
make-a-video, motion-showreel, short-form-edit, style-library, video-storytelling,
website-to-hyperframes) are copied from https://github.com/nateherkai/herk-edit-kit
(commit 10511e5), MIT. The kit itself lives in `/herk-edit-kit` (without Nate's
video-projects and showcase videos; legacy `short-form-video` skill left out).
Paths to `.claude/skills/...` inside the kit were changed to `../.claude/skills/...`.
